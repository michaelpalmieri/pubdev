---

# Objective

Deploy four Nested ESXi 9.0.1 hosts using:

* One customized ESXi ISO
* Ubuntu Apache Kickstart server
* DHCP Reservations
* Unsupported CPU Bypass
* Static management addressing
* Automated installation

## Step 2 - Create Kickstart Directory

### Purpose

### Command

```bash
sudo mkdir -p /var/www/html/ks
```

### Verification

```bash
ls -ld /var/www/html/ks
```

---

## Step 3 - Create bootstrap.cfg

### Purpose

Generates a host-specific Kickstart based on the DHCP-assigned source IP.

### Command

```bash
sudo tee /var/www/html/ks/bootstrap.cfg > /dev/null <<'EOF'
#!/usr/bin/env python3
import os

hosts = {
    "172.16.3.6": ("vcf01.esx.local", "172.16.3.6"),
    "172.16.3.7": ("vcf02.esx.local", "172.16.3.7"),
    "172.16.3.8": ("vcf03.esx.local", "172.16.3.8"),
    "172.16.3.9": ("vcf04.esx.local", "172.16.3.9"),
}

client_ip = os.environ.get("REMOTE_ADDR", "")
hostname, ip = hosts.get(client_ip, ("unknown.esx.local", client_ip))

print("Content-Type: text/plain")
print()

print(f"""vmaccepteula
install --firstdisk=local --overwritevmfs
rootpw VMware123!
network --bootproto=static --device=vmnic0 --ip={ip} --netmask=255.255.255.224 --gateway=172.16.3.1 --nameserver=172.16.3.1 --hostname={hostname} --vlanid=4095
reboot
""")
EOF
```

### Verification

```bash
cat /var/www/html/ks/bootstrap.cfg
```

Expected:

Python script displayed.

---

## Step 4 - Make bootstrap.cfg Executable

### Purpose

Allows Apache CGI execution.

### Verification

```bash

```


---

## Step 5 - Create Apache CGI Configuration

### Purpose

Allows execution of CGI scripts.

### Command

```bash
sudo tee /etc/apache2/conf-available/ks-cgi.conf > /dev/null <<'EOF'
<Directory "/var/www/html/ks">
    Options +ExecCGI
    Require all granted
    AddHandler cgi-script .cfg
</Directory>
EOF
```

### Verification

```bash
cat /etc/apache2/conf-available/ks-cgi.conf
```

## Step 13 - Modify BIOS BOOT.CFG

### Purpose

Adds:

* Kickstart URL
* Unsupported CPU bypass

### Command

```bash
sed -i '' 's|kernelopt=.*|kernelopt=runweasel allowLegacyCPU=true ks=http://172.16.3.30/ks/bootstrap.cfg|' ~/esxi-kickstart/extracted/BOOT.CFG
```

### Verification

```bash
grep kernelopt ~/esxi-kickstart/extracted/BOOT.CFG
```

Expected:

```text
kernelopt=runweasel allowLegacyCPU=true ks=http://172.16.3.30/ks/bootstrap.cfg
```

---

## Step 14 - Modify EFI BOOT.CFG

### Command

### Verification

```bash
grep kernelopt ~/esxi-kickstart/extracted/EFI/BOOT/BOOT.CFG
```

---

## Step 15 - Install xorriso

### Command

```bash
brew install xorriso
```

### Verification

```bash

```

---

## Step 16 - Rebuild ISO

### Command

```bash
xorriso \
-indev ~/Downloads/VMware-VMvisor-Installer-9.0.1.0.24957456.x86_64.iso \
-outdev ~/esxi-kickstart/ESXi-9.0.1-Kickstart.iso \
-map ~/esxi-kickstart/extracted/BOOT.CFG /BOOT.CFG \
-map ~/esxi-kickstart/extracted/EFI/BOOT/BOOT.CFG /EFI/BOOT/BOOT.CFG \
-boot_image any replay
```

### Verification

```bash

```

Expected:

```text
Boot record  : El Torito
```

# Lessons Learned

1. ESXi 9 requires installer network access before Kickstart download.
2. DHCP reservations provide deterministic host identity.
3. CGI-generated Kickstart was more reliable than dynamic %pre scripts.
4. Both BOOT.CFG and EFI/BOOT/BOOT.CFG must be modified.
5. allowLegacyCPU=true converts unsupported CPU failures into warnings.
6. VMware MAC addresses must be unique across all NICs.
7. CPU warnings are acceptable; CPU errors are not.
